# Лабораторная работа №2: камера и освещение

Вариант 2 — правильный октаэдр из ЛР №1. Программа использует C++, Vulkan,
GLFW и ImGui; основой послужил выданный преподавателем стартовый проект.

## Сборка на Windows

Нужны Vulkan SDK с `glslc`, CMake 3.20+, Git и Visual Studio 2022 с C++.
При первой конфигурации CMake скачивает GLFW, vk-bootstrap, VMA и ImGui.
Откройте PowerShell в папке `lab2` и выполните:

```powershell
$env:VULKAN_SDK = 'C:\VulkanSDK\1.4.350.0'
$env:PATH = "$env:VULKAN_SDK\Bin;$env:PATH"
$env:VK_LAYER_PATH = "$env:VULKAN_SDK\Bin"
cmake --preset msvc-debug
cmake --build build-debug --config Debug --parallel
.\build-debug\Debug\lab2-camera-lighting.exe
```

Укажите свой путь к SDK. Запускайте программу из папки `lab2`: она загружает
скомпилированные шейдеры по относительным путям. При длинном пути к проекту
Windows может помешать CMake скачать зависимости; в этом случае скопируйте
`lab2` в короткий путь, например `C:\cg\lab2`.
`VK_LAYER_PATH` позволяет Vulkan loader найти validation layer из SDK. Если
SDK установлен и слой доступен системе через реестр, эта строка необязательна.

## Что показать

1. В **Camera** измените позицию, поворот и угол обзора; кнопка Reset camera
   возвращает исходный вид.
2. В **Directional and ambient** измените цвет, направление и интенсивность
   направленного света и фонового освещения.
3. В **Point lights** добавьте источник, измените его позицию, цвет и
   интенсивность, затем удалите. Повторите для **Spot lights**, меняя также
   направление и внутренний/внешний углы.
4. В **Objects and material** измените альбедо, цвет блика и коэффициент
   блика октаэдра; добавьте другие объекты. Включите и выключите
   **Show light markers and cones**.

## Реализация

Грани октаэдра построены из 24 вершин. Для каждой грани нормаль вычисляется
векторным произведением двух её рёбер. Вершинный шейдер переносит вершины и
нормали в мировое пространство. Фрагментный шейдер вычисляет фоновую,
диффузную и зеркальную составляющие по Блинну–Фонгу. Точечные и прожекторные
источники затухают как `1 / max(r², 0.01)`; край конуса прожектора сглажен
между внешним и внутренним углом.

Набор дескрипторов 0 содержит общие данные сцены и два storage-буфера с
массивами источников. Набор 1 содержит матрицы и материал конкретного
объекта. Кубы и линии конусов рисуются отдельными pipeline с постоянным
цветом без освещения Блинна–Фонга. Основная логика находится в
`source/application.cpp`; работа окна, swapchain и кадров — в
`source/graphics_internal.cpp`.
